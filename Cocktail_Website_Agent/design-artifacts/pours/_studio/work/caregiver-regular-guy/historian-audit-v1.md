# Fact audit v1

Verdicts: PASS · FIX (wording) · STRIKE. Sources: Oxford IRISH COFFEE pdf 1075–1077; Joy pdf 307; Codex p. 268; Matrix pdf 72.

| A1 | epigraph | "Within three years" | FIX | Oxford gives late 1944/early 1945 and "By 1947". If the start is late 1944 and the offer is dated anywhere in 1947, the gap can run past three years; the span is not on the page. Use Oxford's own date: "By 1947, …" |
| A2 | epigraph | "everyone off the plane got one" | FIX | Oxford: "offered to all travelers deplaning at Shannon". Offered ≠ everyone got/drank one. "…everyone off the plane was offered one." |

| A7 | y2 | syrup, bigger glasses, can | PASS | pdf 1076–1077 ("With fame came adulteration"). |

"The way Sheridan did" is Oxford's phrase; fine unquoted, don't put it in quotation marks. |
