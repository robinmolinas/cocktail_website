It's a whiskey Daisy made the old way, the version served in a cocktail glass. 50 ml bourbon, 22.5 lemon, 15 simple syrup, 7.5 orange curaçao, then a tablespoon of soda on top. Without it the drink is still balanced, so it's there for the story and the taste, not to fix the numbers.
