The bourbon and the water together always make 60 ml, and the stronger the barrel, the more of that is water: 50% is 56 + 4, 55% is 51 + 9, 60% is 46.5 + 13.5, 65% is 43 + 17. Every stop gives the same numbers as 60 ml at 46.5%, so any single barrel lands where Blanton's does. That's physics, and it happens to be the only honest version of "read the label before you stir".
