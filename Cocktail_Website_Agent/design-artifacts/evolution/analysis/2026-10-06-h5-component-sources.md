# H5 component sources: React Bits, 21st.dev, Magic UI, Paper Shaders

2026-10-06. A research audit only. No production code was changed.

## What I checked

- **React Bits.** I read the GitHub tree and source (DavidHDev/react-bits, about 48.5k stars, last push 2026-10-03, about 213 TS+Tailwind components). For the shortlist I read the imports and props of the actual source files.
- **21st.dev.** I used its markdown twins (`.md` pages and `llms.txt`) and search results. I did not open live previews.
- **Magic UI** and **Paper Shaders.** I read their GitHub source and licences. Paper Shaders surfaced because 21st.dev's metaballs component is adapted from it.

**The app has no animation dependencies today.** Its only runtime dependencies are `react`, `react-dom` and `@vercel/analytics`. Every option below either adds a dependency or has to be hand-ported.

## Shortlist

**Reduced motion:** none of the shortlisted WebGL or canvas components check `prefers-reduced-motion`. Across the React Bits files I downloaded, only DodgeField does. **Touch:** most React Bits interactive effects listen for `mousemove`, so on phones they turn into autoplay or do nothing.

## What adoption would mean

- **Copying React Bits shaders** adds `ogl`. It is small but its exact gzip size is **unverified**.
- **Anything using `three` or R3F** adds a large bundle. That is not justified for a single screen.
- **Paper Shaders** adds two packages that are still pre-1.0, so pin the version.
- **The leanest route** is to hand-port the two or three shader ideas into one raw WebGL canvas behind H5. It would have DPR capped at about 1.5, pause when hidden, and show a static frame under reduced motion. The word bubbles stay as DOM elements driven by CSS transforms, so taps, focus and screen readers keep working.

## Recommendation

**(a) Round 1, accretion and gravity in.**
1. Use the metaball merge (MetaBalls or Paper metaballs). When a word is tapped, a bead of the seed light leaves the bubble, travels a curved inward path, and merges into the self's edge through the smooth-min field. The self then grows a little.
2. Move the bead with a critically damped lerp, as in Magic UI Particles. It slows as it nears the self and has no overshoot.
3. Clear the word with a blur-dissolve (the BlurText technique, in CSS).

**(b) Round 2, outward attraction.**
1. The self pushes a soft bulge or tide toward the chosen word, like a gentle Ferrofluid. It is a swell, never spikes.
2. Each chosen word then settles into a very slow parked orbit (the Orbiting Circles technique), taking at least 60 seconds per revolution, with no drawn path. The three words become the self's moons.

**(c) The self-circle.** A single-colour living orb: the Orb or Paper smoke-ring technique rebuilt around one seed-colour uniform, with slow noise breathing and an additive glow, so the seed appears only as light. Reduced motion shows one still frame.

**Avoid:** Galaxy, Particles fields, LiquidEther, SplashCursor, Ballpit, GooeyNav, ClickSpark, Magnet, Hyperspeed, and any visible orbit-path rings. They read as an AI or hero-section demo, are gamified, or are too heavy for phones.
