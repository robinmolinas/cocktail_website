# Trial fonts — comparison only, never ship

`pp-neue-montreal/` holds PP Neue Montreal from Pangram Pangram's **Free for Personal Use v3.0** download (EULA included). That licence covers testing, proofing and pitches, not a commercial project. These files exist only to render the type comparison. Do not copy them into `dionysus-experience/` or deploy them.

If Neue Montreal is chosen, buy a web licence from https://pangrampangram.com/products/neue-montreal and self-host the licensed WOFF2 files. Note that the trial omits Medium.

Satoshi and Switzer load from the Fontshare CDN (ITF Free Font License), so they are not stored here.
