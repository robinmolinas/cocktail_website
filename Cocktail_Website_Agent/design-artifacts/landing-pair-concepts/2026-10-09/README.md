# Dionysus — two-person landing concepts

Created 9 October 2026 using the built-in image generation tool and the active landing artwork as visual references.

## Purpose

Explore an adult man and woman in the existing dark, gold-rimmed double-exposure art direction. Each board shows BEFORE on the left and REVEALED on the right. These are art-direction studies; no landing-page assets or application behavior have been changed.

## Directions

1. **Two worlds** — outward-facing profiles with two distinct ingredient constellations. Strongest initial direction for maintaining mystery and allowing independent exploration. The paired composition may still suggest a relationship; test how guests interpret it.
2. **Layered lives** — staggered profiles facing the same direction. Closest to the current profile artwork and visually fluid; overlapping bodies create more visual complexity and require care in the mobile crop.
3. **Open portraits** — more visible faces and three-quarter views. A more personal, welcoming campaign treatment; less abstract than the current silhouette. The generated man sits slightly higher and the portraits touch at the shoulder, so equality of scale and spacing would need refinement if selected.

## Recommendation

Start by testing Two worlds against the current single portrait. Retain the same entrance to the journey and allow the pointer to uncover either person's individual inner world. The pictured ingredient combinations are visual examples, not gender-based recommendations or validated drink recipes.

Ask test participants what the page seems to offer: discovering their own cocktail, an experience for a couple, or a choice between male and female cocktails. Their interpretation is the useful signal alongside aesthetic preference.

Two people broaden representation, while future casting can also vary age, appearance and gender expression. Equal visual weight and rich, mixed ingredient vocabularies matter more than assigning opposite flavor identities.

## Production note

The boards keep approximately matching before/revealed positions, but they are not production-ready paired layers. Final source images need identical background and silhouette geometry, room for the actual copy and CTA, and desktop/mobile crop review. The original artwork remains the source of truth until a direction is selected.
