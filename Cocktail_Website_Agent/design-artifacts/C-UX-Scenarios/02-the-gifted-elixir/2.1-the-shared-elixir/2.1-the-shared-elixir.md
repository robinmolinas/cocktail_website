# 2.1 · The Shared Elixir

Updated 8 October 2026 · Phone-first responsive gift arrival

**Purpose:** let a recipient admire a friend's cocktail, use the recipe and begin their own journey.

TheReading in gift mode opens through dark, presents the cocktail/name and recipe, and offers **Discover the spirit within you**. The private owner reading is withheld. This is the same reading room with a different entry state, not a miniature ink overflow or a new page design.

The current implementation reads a fragment gift. The target Epic 2 contract adds persisted `/pour/:id` links, minimal fragment fallback and dynamic OG; these remain implementation work. A stored pour has identity/source metadata, never private reading text. House examples are separate authored constants.

Verify portrait scene/name fit, recipe usability, absence of owner reading, return to the Entrance and handling of broken gifts. Server routing and unfurl require separate verification when implemented.
