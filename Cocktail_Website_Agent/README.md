# Cocktail_Website_Agent

The web experience is **`dionysus-experience/`** (Vite + React 19, deployed from there). Start with its README.

| Folder | What it holds |
|---|---|
| `dionysus-experience/` | The app: journey, shared matching core, reading, e2e checks |
| `agent/` | Spec, architecture spine, matching model and its analysis |
| `design-artifacts/` | UX specifications, pour dossiers, Pour Studio workspace |
| `_bmad-output/` | Planning and build records (initiatives, epics, specs) |
| `Knowledge base/` | Background cocktail research |

A first Vite prototype sat in this folder until 2026-10-14. It was retired then: it was untouched since the initial commit, never deployed, and its lockfile no longer installed. To read it, check out commit `df239f5`.
